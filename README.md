# SoundTrackMaster

Official website of **SoundTrackMaster** — independent music artist.

Music beyond the ordinary: written, produced, mixed and mastered in-house, and released across Spotify, Apple Music, YouTube Music, Amazon Music, iTunes and JioSaavn.

**Live site:** https://soundtrackmaster.github.io/

## What's in this repository

| File | Purpose |
| --- | --- |
| `index.html` | The entire website — one self-contained page (styles, script, artwork and the live music catalogue are all inside it) |
| `soundtrackmaster-intro.mp4` | The 1080p intro film that plays when the site opens |

There is no build step and no dependencies — GitHub Pages serves these files exactly as they are.

## How the site works

- **Music catalogue** — on every visit the page reads the current release list (titles, dates, durations, official previews and cover art) and renders the cards itself, so new releases appear automatically without any edits to this repository.
- **Contact** — the contact form on the site delivers messages directly to the studio inbox.
